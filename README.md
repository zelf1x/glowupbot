# 📚 Telegram Bot для напоминаний об учебе и занятиях

Умный и надежный Telegram-бот для управления расписанием занятий (английский язык, репетиторы, курсы) и дедлайнами домашних заданий с поддержкой часовых поясов и кастомизируемых интервалов оповещений.

Стек: **Python 3.12+**, **aiogram 3.x**, **aiosqlite**, **APScheduler**, **Pydantic Settings**.

---

## ✨ Возможности

1. **Регулярное расписание уроков (Weekly Schedule):**
   - Добавление повторяющихся занятий по дням недели (например, *«Английский разговорный клуб»*, каждый вторник и четверг в `19:00`).
   - Настройка интервалов напоминаний: за 1 день, за 2 часа, за 1 час, за 30 мин, за 15 мин и прямо в момент начала урока.
   - Возможность временно приостановить (`⏸`) или удалить любое занятие в 1 клик.

2. **Разовые напоминания и дедлайны (One-time Tasks):**
   - Поддержка естественного языка:
     - `завтра в 18:00`
     - `сегодня 20:30`
     - `28.11 15:00`
     - `+30м` (через 30 минут), `+2ч` (через 2 часа)

3. **Корректные часовые пояса (Timezone Support):**
   - Автоматическая адаптация времени напоминаний под часовой пояс пользователя (Москва, Екатеринбург, Алматы, Ташкент или любой другой по стандарту IANA).

4. **Высокая отказоустойчивость:**
   - Данные хранятся в асинхронной базе данных SQLite (`aiosqlite`).
   - При перезапуске бота ни одно напоминание не потеряется.

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Откройте в Telegram диалог с официальным ботом [@BotFather](https://t.me/BotFather).
2. Отправьте команду `/newbot` и следуйте инструкциям (задайте имя и юзернейм бота).
3. Скопируйте выданный токен вида: `7123456789:AAHq_...`.

### 2. Настройка файла `.env`
Перейдите в директорию бота и скопируйте шаблон:
```bash
cp .env.example .env
```
Откройте файл `.env` и вставьте ваш токен:
```ini
BOT_TOKEN=7123456789:AAHq_...
DEFAULT_TIMEZONE=Europe/Moscow
DATABASE_PATH=reminders.db
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск бота
- На Windows: дважды кликните по файлу `run.bat` или выполните:
  ```bash
  python main.py
  ```
- На Linux / macOS:
  ```bash
  python3 main.py
  ```

├── test_app.py         # Автоматические тесты функционала
